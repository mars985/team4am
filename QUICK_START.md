# ⚡ Quick Start - Play Both Games Now!

## 🚀 Super Fast Setup (2 Minutes)

### Step 1: Start Backend (Terminal 1)
```bash
cd engine-backend
npm install  # Only first time
npm run dev
```
✅ You should see: "Server running on port 5000"

### Step 2: Start Frontend (Terminal 2)
```bash
cd engine-frontend
npm install  # Only first time
npm run dev
```
✅ You should see: "Local: http://localhost:5173"

## 🎮 Play Games

### Strands (Word Game) - Single/Multiplayer
```
http://localhost:5173/strands
```
- Drag letters to form words
- 3+ letters minimum
- 10 points per letter
- Multiple players can play together

### Join The Dots - 2 Player Game
```
Tab 1: http://localhost:5173/dots  → Player 1 (Blue)
Tab 2: http://localhost:5173/dots  → Player 2 (Red)
```
- Take turns drawing lines
- Complete boxes to score
- Most boxes wins!

## 🎯 That's It!

You're ready to play! Open the URLs above and enjoy! 🎉
